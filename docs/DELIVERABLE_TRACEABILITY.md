## Demo readiness on 2026-11-09

The project is **ready for a local demo using the existing data**. The frontend lint, typecheck, and 19-route production build passed; Python source compilation and 14 focused backend tests passed. Live HTTP/RBAC, Admin CRUD, MongoDB RUD, strategy-document CRUD, vector index/search, and SQL query/DML flows were exercised. The only credential-dependent item is a real FastF1 protected-session import, which requires F1TV Access and is outside the public Jolpica import demonstration. The full Starlette TestClient suite still stalls in Python 3.14, though the relevant HTTP role flows passed against the running API.

The website route/action inventory is in the `Next.js analytics UI` row and the updated `docs/DEMO_SCRIPT.md`. Keep all CRUD demonstrations on isolated test fixtures; do not modify imported demo records or initialize the existing database for a presentation.

## Scope notes from supplied reference

The attached PDF is treated as design material. Its season-specific `DRIVER_TEAM` relationship and separation of high-frequency telemetry into MongoDB are useful inputs. The full project brief additionally requires security, audit, strategy and analytical entities, so the final schema may extend the PDF. The vector database is conditional in the brief; its inclusion will be justified rather than assumed.
